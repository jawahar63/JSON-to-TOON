Frequently Asked Questions

What is TOON format?
TOON (Token-Oriented Object Notation) is a compact, structured data format that encodes JSON as a human-readable spreadsheet-like notation designed to maximize information density while minimizing token count in LLM context windows.

How much can TOON reduce my token usage?
Typical reductions range from 30–60%. Uniform object arrays and tabular data see the highest compression.

Is this tool free and private?
Yes — completely free, no sign-up required. All conversion happens in your browser; no data is ever sent to a server.
